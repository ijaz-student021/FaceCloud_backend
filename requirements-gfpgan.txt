# The isolated worker environment that can also run GFPGAN face restoration.
#
#   python3.12 -m venv .runtime/venvs/gfpgan
#   .runtime/venvs/gfpgan/bin/pip install -r requirements-gfpgan.txt
#
# It is the backend's own requirements plus PyTorch and the GFPGAN stack, so the
# worker can never drift from what the application imports. (It used to repeat
# the backend's list by hand and had fallen behind: without `cryptography` the
# worker could not start Django at all.)
#
# Python 3.12 or newer is required by Django 6. GFPGAN 1.3.8 depends on BasicSR
# 1.4.2, which imports a module torchvision removed in 0.17; enhancement/gfpgan.py
# supplies the one missing name at import time, so a current torchvision works.
# The constraints file pins the binary packages the stack is known to load with.
-c requirements-gfpgan-constraints.txt
-r requirements.txt
torch
torchvision
gfpgan==1.3.8
basicsr==1.4.2
facexlib==0.3.0
