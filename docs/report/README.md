## How it relates to the repository

The report is a **snapshot** of the project as submitted in November 2026. It does not change when the code does.
The Markdown documents in [`docs/`](../README.md) are the maintained record: [`FEATURES.md`](../FEATURES.md) is the current feature
catalogue, [`deployment/VPS_DEPLOYED_STATE.md`](../deployment/VPS_DEPLOYED_STATE.md) describes what is deployed, and
[`api/API_REFERENCE.md`](../api/API_REFERENCE.md) lists the API. Where the report and these documents differ, the Markdown
documents describe the later state.

The PDF contains the authors' names and student numbers. It contains no passwords, keys or server addresses.
