# FaceCloud API reference

Generated by `scripts/export_api_docs.py` from the OpenAPI schema (221 operations). Interactive version: `/api/docs/` (Swagger UI) and `/api/redoc/`; machine-readable: `docs/api/openapi.yaml`. `*` marks a required request field. Every endpoint except those marked public needs `Authorization: Bearer <access token>`.

FaceCloud AI: authenticated facial-image upload, enhancement, validation, identity grouping, reports, sharing and downloads.

## Quick start (the enhancement flow)

1. `POST /api/auth/register/` then `POST /api/auth/verify-email/` (six-digit code), then `POST /api/auth/login/`. Send the returned
   `access` token as `Authorization: Bearer <access>` on every other call (in Swagger UI, press the **Authorize** button and paste the access token). Refresh it with `POST /api/auth/refresh/`.
2. `POST /api/images/upload/single/` (multipart field `file`). The response is an **upload batch**; the image is `images[0]`.
3. `POST /api/enhancements/images/{image_id}/` with `{"level": "auto", "style": "natural"}`. Returns **202** and a result with `status: "queued"`.
4. Poll `GET /api/enhancements/results/{id}/` until `status` is `completed` (or `failed`).
   `enhancement_outcome` says what happened (`enhanced`, `partially_enhanced`, `original_preserved`, `failed`) and `enhancement_summary` is one plain sentence safe to show a user.
5. `GET /api/enhancements/results/{id}/download/` returns the one final image.

## Conventions

* **Errors.** Validation errors (400) are `{"field": ["message"]}`; every other error is `{"detail": "...", "code": "..."}` (see the `ErrorDetail` schema).
  401 means a missing, expired or revoked token; 403 not allowed; 404 not found *or not yours* (other users' data is never revealed); 429 a rate limit.
* **Ownership.** Every call acts on the caller's own data unless the endpoint says it is for administrators or organization roles.
* **Pagination.** List endpoints return a plain array, or a paginated object when `page` or `page_size` is passed.
* **Asynchronous work.** Enhancement, reports, exports and packages are queued jobs: the POST returns 202 and you poll the resource.
* **Images.** Downloads stream through the API after an ownership check; there are no public file URLs (shares use revocable tokens).
* **Identity.** `identity_status` and `identity_verification.state` say whether faces were compared with the upload. They never claim a guarantee.
